# Viva Presentation Workspace

Use this folder to collect viva slides, demo script, screenshots, and speaking notes.

Recommended slide flow:

1. Title
2. Problem background
3. Problem statement
4. Aim and objectives
5. Proposed solution
6. System architecture
7. AI/ML workflow
8. Database design
9. Key features
10. Demo flow
11. Results
12. Testing
13. Challenges
14. Limitations
15. Future work
16. Conclusion
